# Scraping thumbnails

[日本語](scraping.ja.md) | [User manual](README.md)

Scraping downloads artwork for ROMs already visible to the frontend.

1. Connect Wi-Fi and verify Internet access.
2. Check ROM filenames. Clear game names produce better matches than archive
   notes or unrelated tags.
3. Open `START -> Apps -> Scraping`.
4. Select the systems and download type, then start.
5. Leave the device powered until the result screen appears.

Downloaded images are stored on the user volume and used by graphic and gallery
views. A missing match does not stop a game from launching. Correct the ROM
name and scrape again rather than manually changing runtime indexes.

Scraping many systems can take time and creates substantial writes. Use stable
power and free space, and do not sleep or remove Wi-Fi while it is running.
