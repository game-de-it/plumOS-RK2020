RK2020は専用音量buttonがなく、Function/L2 mappingも他機種と異なるため、追加で
[RetroArchのsave・hotkey詳細](user/retroarch-saves-and-hotkeys.ja.md)も日英で用意
しました。

READMEのvisual項目も比較し、本体写真と実機nativeのgraphic、gallery、text screenshot
を掲載しました。本体写真は全EXIF・profile metadataを削除してexportしています。
