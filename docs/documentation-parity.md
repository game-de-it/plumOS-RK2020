# Documentation parity audit

[日本語](documentation-parity.ja.md) | [Documentation index](README.md)

This audit compared RK2020 user documentation with the maintained sets in
plumOS V90S, XU20 V3.2, Pixel2 v2, GKD mini PLUS, and Bubble.

| Common topic | RK2020 document | Status |
| --- | --- | --- |
| User index | [User manual](user/README.md) | Present in both languages |
| Installation and first boot | [Installation](user/install.md) | Present in both languages |
| Basic controls and power | [Controls](user/operation.md) | Present in both languages; RK2020-specific hotkeys included |
| Systems and emulator use | [Emulators](user/emulators.md) | Present in both languages |
| Supported-system catalog | [Supported systems](user/supported-systems.md) | Generated in both languages from the active RK2020 catalog |
| Storage | [Storage and reimaging](user/storage-and-reimaging.md) | Present in both languages; includes residual FAT-data behavior |
| Save data | [Save data](user/save-data.md) | Present in both languages |
| Network and transfer | [Network](user/network.md) | Present in both languages; USB Wi-Fi and SFTP covered |
| Scraping | [Scraping](user/scraping.md) | Present in both languages |
| Updates | [Updates](user/updates.md) | Present in both languages; RK2020 manual-image update policy covered |
| Troubleshooting | [Troubleshooting](user/troubleshooting.md) | Present in both languages |

RK2020 additionally keeps a dedicated bilingual
[RetroArch save and hotkey reference](user/retroarch-saves-and-hotkeys.md),
because its missing volume keys and Function/L2 mapping differ from other
plumOS handhelds.

README visual parity was also checked: the device photograph plus native
graphic, gallery, and text screenshots are present. The photograph was exported
with all EXIF/profile metadata stripped.
